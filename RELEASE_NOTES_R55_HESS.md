# Release notes R55_HESS

R55 refreshes the HESS-targeted reproducibility package after the final
pre-submission hard check.

Increment relative to R54:

- synchronizes the public generated-figure set with the current HESS main
  figures, including `fig05_multimodel_benchmark`;
- updates main figure panel labels to the HESS lower-case bracket style;
- reduces the main-figure font set to an embedded Arial family;
- retains code, tests, dataset registry, derived non-sensitive source data,
  checksum manifest, random-seed registry and Zenodo-ready metadata;
- excludes raw third-party data, active submission manuscripts, cover letters,
  internal review rounds and private files.

The archival DOI exists only after the GitHub release is connected to Zenodo or
the deposition is created manually.
