# GitHub release checklist

Intended repository: https://github.com/Johnsonlijian/earth-deborah-benchmark
Recommended release tag: R55_HESS

1. Push this release-ready directory only; do not push raw data, submission manuscripts, cover letters, rounds or logs.
2. Create a GitHub release using the same tag.
3. If Zenodo GitHub integration is active, confirm that the release is archived and record the DOI.
4. If Zenodo integration is not active, enable it for this repository or create the Zenodo deposition manually using `.zenodo.json`.
5. Insert the final GitHub release URL and Zenodo DOI into manuscript Data/Code availability only after the DOI exists.
