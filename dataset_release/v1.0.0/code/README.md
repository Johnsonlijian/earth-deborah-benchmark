# Analysis code for Dataset version 1.0.0

This folder preserves the analysis scripts accompanying the Dataset release.
Numerical algorithms, parameters and source files are unchanged from the
reviewed data package. The public GitHub repository also stores this exact
folder under dataset_release/v1.0.0/code; the root README records its commit.

The archive layout is a deposit layout. Historical scripts expect a working
tree with reports/tables/, reports/figures/, data/external/ and the original
script paths. Follow REPRODUCIBLE_RUNBOOK.md and
metadata/SOURCE_MANIFEST_R68.csv at the Dataset root to reconstruct that layout.
The archived tables are derived products, not raw provider time series.
Raw inputs are obtained from the cited providers under their applicable terms.

LICENSE_MIT.txt applies to this code. Provider data and third-party libraries
remain governed by their own terms. Code checksums identify this snapshot.
