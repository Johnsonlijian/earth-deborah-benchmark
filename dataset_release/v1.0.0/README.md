# Dataset version 1.0.0 companion code

Dataset: A benchmark dataset of null-calibrated streamflow spectral-memory diagnostics for five CAMELS-family archives, with open rainfall-runoff model outputs for CAMELS-GB v2
Creator: Lijian Ren.
Dataset DOI: https://doi.org/10.5281/zenodo.22055294

The code/ directory is byte-for-byte identical to code/ in the corresponding
Zenodo Dataset ZIP. CODE_SHA256.csv covers all 89 files, including the code
README and MIT licence. Scientific scripts and environment definitions were
copied unchanged; no numerical analysis was rerun for this public release.

Use the Zenodo ZIP for all derived data, figures, licence notices and the
source-to-archive map. DATASET_RUNBOOK.md explains how to reconstruct the
historical execution layout before invoking analysis scripts. This directory
is an archival snapshot, not a self-contained raw-data environment.

The older repository-root implementation and commit
6d5804208b46a39cb26aa8650a3eac8cd442e8e1 remain available as historical artifacts.
They are distinct from the Dataset-specific code snapshot preserved here.
Use this versioned directory when reproducing Dataset version 1.0.0.

Code is MIT; author-created Dataset data/documentation are CC BY 4.0.
Raw third-party archives, submission manuscripts and reviewer correspondence
are excluded from this update.
