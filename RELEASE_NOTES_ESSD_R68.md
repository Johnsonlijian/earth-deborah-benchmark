# ESSD R68 Public-Repository Update

Date: 2026-08-22

This update retargets the public software/reproducibility repository from the
earlier HESS-facing state to the bounded ESSD data-description package.

## Added

- released R62 decision-test source tables;
- the R62 analysis script and a public scientific protocol transcription;
- released-table-only ESSD figure scripts;
- ESSD-facing Figures 1-5 and Supplementary Figure S1 in vector and review
  formats;
- Figure 5 source/output provenance;
- updated runbook, release metadata, and source-data indexes.

## Scientific boundary preserved

- the decision-test result is null and is reported as such;
- observed De-axis reductions are not promoted to storage-causality evidence;
- CAMELS-DK remains a boundary case;
- strict matched-AR(1) artifact-floor comparisons remain negative in
  null-adjusted terms.

## Excluded

No manuscript, cover letter, reviewer material, submission record, workflow
round, credential, raw third-party archive, or private author/funding file is
included. No dataset DOI is claimed or fabricated by this commit.
