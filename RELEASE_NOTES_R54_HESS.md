# Release notes R54_HESS

Release-ready reproducibility package for the HESS-targeted streamflow
spectral-memory benchmark.

Included contents:

- code, tests and configuration for derived analyses;
- dataset registry and reproducible runbook;
- derived non-sensitive source-data CSVs;
- generated publication figures;
- random-seed registry, checksum manifest and citation metadata;
- Zenodo-ready metadata without raw third-party data or active submission files.

This package is release-ready. The archival DOI exists only after a GitHub
release is connected to Zenodo or the deposition is created manually.
